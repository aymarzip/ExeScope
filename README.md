# ExeScope — Dynamic Analysis Suite for Windows

**ExeScope** — полноценное приложение для динамического анализа подозрительных исполняемых файлов (`.exe`) в изолированной тестовой среде (песочнице / чистой виртуальной машине).

Приложение разработано на **C# / .NET 8** и **WPF** с соблюдением принципов чистой архитектуры, безопасной работы с путями и потокобезопасной пакетной записи.

---

## Возможности

* **Сценарий «Ожидать запуск»**: анализатор заранее активирует сборщики телеметрии и ждет, когда пользователь самостоятельно запустит целевой файл (анализатор не запускает исследуемый файл самостоятельно).
* **Сведения о файле до запуска**: автоматический расчет SHA-256, проверка канонического пути, размера и статуса цифровой подписи Authenticode.
* **Обнаружение подмены файла**: проверка хеша при запуске для обнаружения изменения файла на диске после его выбора.
* **Иерархическое отслеживание процессов**:
  * Точная идентификация процессов по паре `(PID, StartTimeUtc)` для защиты от переиспользования PID (PID Recycling).
  * Рекурсивное отслеживание дочерних процессов и модулей (DLL).
  * Продолжение записи после завершения основного процесса, пока активны его дочерние процессы.
  * Фиксация повторных запусков в виде отдельных сессий.
* **Сбор системных событий**:
  * **Файловая система**: создание, открытие, чтение, запись, переименование, удаление. Четкое разделение журнала операций и байтов файла.
  * **Реестр Windows**: создание, открытие и удаление ключей, установка и удаление значений.
  * **Сеть**: фиксация активных TCP/UDP сокетов и DNS-запросов с точной привязкой к PID через Win32 IP Helper (`GetExtendedTcpTable`) и Kernel ETW.
  * **Захват пакетов PCAPNG**: запись сырого трафика в стандартном формате Wireshark PCAPNG со строгой фильтрацией по портам отслеживаемых процессов.
* **Высокопроизводительная обработка больших объёмов данных**:
  * Кольцевые буферы (`RollingBuffer`) для плоского использования памяти независимо от длительности анализа.
  * Пакетная неблокирующая запись на диск (до 1000 событий за такт) с адаптивным сбросом буфера.
  * Полная виртуализация строк и колонок в DataGrid (`Recycling`, `Item` scrolling unit) и пакетные UI-уведомления (`BulkObservableCollection`) для плавной работы интерфейса на 100k+ событий.
  * Дебаунс и оптимизированная предикатная фильтрация без промежуточных строковых аллокаций.
* **Безопасное сохранение артефактов**:
  * Неблокирующее копирование созданных/измененных файлов с флагами совместного доступа (`FileShare.ReadWrite | FileShare.Delete`).
  * Фиксация оригинального пути, момента копирования, SHA-256 и флага изменения файла во время чтения.
  * Ограничение по белому списку каталогов, максимальному размеру файла и общему бюджету хранения.
  * 100% защита от Path Traversal (выхода за пределы папки сессии) и опасных имен DOS/NTFS потоков.
* **Стандартизованный пакет результатов сессии**:
  * `session.json` — конфигурация, метаданные, возможности и ограничения.
  * `events.jsonl` — потоковый лог событий в формате NDJSON.
  * `process-tree.json` — иерархическое дерево процессов.
  * `artifacts/` — изолированные копии файлов с безопасными именами.
  * `artifacts-index.jsonl` — журнал сохранения артефактов.
  * `network.pcapng` — дамп трафика (при включении).
  * `report.html` — автономный красивый интерактивный отчет (работает полностью offline, всё экранировано).
  * `diagnostics.log` — журнал работы анализатора и фиксация потерь буфера.
* **Безопасный тестовый образец (`ExeScope.TestTarget`)**:
  * Тестовый исполняемый файл для сквозной проверки всех подсистем (файлы, дочерний процесс, реестр `HKCU\Software\ExeScopeTest`, локальный HTTP/TCP сервер).

```
ExeScope/

│   ├── ExeScope.Core/           # Модели данных, sanitizers, хеши, Authenticode, BoundedChannel

    └── ExeScope.Tests/          # Модульные и интеграционные тесты (xUnit)
```

## Инструкция по сборке

### Требования
* Операционная система: Windows 10/11
* Установленный **.NET 8.0 SDK** (или новее)

### Сборка через PowerShell
```powershell
.\build.ps1 -Configuration Release
```

### Сборка через Командную строку (CMD)
```cmd
build.bat Release
```

### Сборка вручную через .NET CLI
```bash
# 1. Восстановление зависимостей
dotnet restore ExeScope.sln

# 2. Сборка решения
dotnet build ExeScope.sln -c Release --no-restore

# 3. Запуск тестов
dotnet test tests/ExeScope.Tests/ExeScope.Tests.csproj -c Release --no-build
```

## Запуск приложения

Исполняемый файл графического интерфейса после сборки:
```

```

Тестовый целевой файл для безопасной проверки:
```
src\ExeScope.TestTarget\bin\Release\net8.0-windows\ExeScope.TestTarget.exe
```

## Безопасность и изоляция среды

> **Внимание:** ExeScope предназначен для анализа в изолированной виртуальной машине (VirtualBox / VMware / Hyper-V). Не запускайте неисследованный вредоносный код на основной рабочей системе. Подробные рекомендации приведены в [USER_MANUAL.md](USER_MANUAL.md) и [ARCHITECTURE.md](ARCHITECTURE.md).
