# ExeScope Pre-built Release Binaries

Скомпилированные исполняемые файлы для Windows x64.

## Состав

- **ExeScope.UI.exe**: графический интерфейс анализатора.
- **ExeScope.TestTarget.exe**: безопасный тестовый образец для проверки всех источников телеметрии (файлы, дочерние процессы, реестр, локальная сеть).
